# stack-queue-deque

Implementing a stack, queue, and a dequeue from scratch using both linked lists and arrays with the use of classes, constructors, and methods. Handle data modifications with member functions such as pop, print, push, and resize while instantiating objects to create test sequences with at least 10 operations.

Design Purpose
- Reused pop and push functions for data structures that perform the same data modification such as queue and deque (pop_forward and push_back functions)
- Recorded the validity and every instance of a data modification besides the constructor in the class implementation and the resize function in the array implementation
  
Time and Space complexity purpose
- Understand the time complexity of all the aforementioned methods
- Complete the member functions in the lowest time complexity where they are O(1) in most cases

*Project uses VS code and C++, requiring a compiler and editor
